# شاشة برامج مركز حمدان بن راشد آل مكتوم للموهبة والابتكار

شاشة عرض للتلفاز (55 بوصة، 16:9) بهوية مؤسسة حمدان بن راشد آل مكتوم للعلوم الطبية والتربوية، تتبدّل تلقائياً بين شريحتين: **البرامج الحالية** و**البرامج القادمة**، مع **لوحة إدارة** لمشرف واحد.

| الصفحة | الرابط | لمن |
|---|---|---|
| شاشة التلفاز | `index.html` | تُفتح على التلفاز |
| لوحة الإدارة | `admin.html` | للمشرف فقط (اسم مستخدم + كلمة مرور) |

## التشغيل على التلفاز
1. افتح رابط `index.html` في متصفح التلفاز (أو جهاز متصل به مثل Fire TV Stick / Chromecast with Google TV / حاسوب صغير).
2. اضغط مرة على الشاشة للعرض بملء الشاشة.
3. الشاشة تحدّث المحتوى تلقائياً كل دقيقة — أي تعديل من لوحة الإدارة يظهر دون لمس التلفاز.
- اختصارات لوحة المفاتيح: ← و → للتنقل بين الشرائح، المسافة للإيقاف المؤقت.

**التكلفة: مجاني بالكامل** — الاستضافة على GitHub Pages، والبيانات والصور على Supabase (الخطة المجانية).

---

## التجربة فوراً (دون أي إعداد)

افتح `index.html` في المتصفح (يُفضّل عبر خادم محلي أو بعد الرفع). ما دام ملف `config.js` فارغاً يعمل الموقع في **الوضع التجريبي** ببرامج نموذجية، وتُحفظ التعديلات في متصفحك فقط.
لوحة الإدارة التجريبية: `admin.html` — اسم المستخدم `admin` وكلمة المرور `admin123`.

---

## النشر على الإنترنت (حوالي 20 دقيقة، مرة واحدة)

### الخطوة 1 — قاعدة البيانات (Supabase)
1. أنشئ حساباً مجانياً على **supabase.com** ثم **New project**. اختر أقرب منطقة متاحة، واحفظ كلمة مرور قاعدة البيانات في مكان آمن.
2. من القائمة الجانبية افتح **SQL Editor** ← الصق محتوى الملف `supabase/schema.sql` كاملاً ← **Run**.
   (ينشئ الجداول، وصلاحيات الحماية، ومكان تخزين الصور، و4 برامج نموذجية يمكنك حذفها لاحقاً.)
3. افتح **Authentication ← Sign In / Providers** وأوقف خيار **Allow new users to sign up** حتى لا يستطيع أحد إنشاء حساب.
4. افتح **Authentication ← Users ← Add user ← Create new user**:
   - Email: `admin@hbrc-admin.local`
   - Password: كلمة مرور قوية (8 أحرف على الأقل)
   - فعّل **Auto Confirm User**
5. افتح **Project Settings ← API** (أو **API Keys**) وانسخ:
   - **Project URL**
   - **anon / publishable key** (المفتاح العام — وليس `service_role` السري)

### الخطوة 2 — ربط الموقع
افتح `config.js` والصق القيمتين:
```js
SUPABASE_URL: "https://xxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
```

### الخطوة 3 — الاستضافة المجانية (GitHub Pages)
1. أنشئ حساباً على **github.com** ثم مستودعاً جديداً **Public** باسم مثل `hbrc-programs`.
2. **Add file ← Upload files** وارفع كل محتويات المجلد (مع مجلدي `assets` و`supabase` و`.github`).
3. **Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save**.
4. بعد دقيقة يصبح الموقع على: `https://اسم-حسابك.github.io/hbrc-programs/`
   ولوحة الإدارة على: `https://اسم-حسابك.github.io/hbrc-programs/admin.html`

> بديل أسرع: اسحب المجلد كاملاً إلى **app.netlify.com/drop** فيعطيك رابطاً فوراً (مجاني أيضاً).

### الخطوة 4 — إبقاء قاعدة البيانات نشطة
مشاريع Supabase المجانية قد تتوقف مؤقتاً بعد أسبوع دون أي زيارة. الملف `.github/workflows/keepalive.yml` يمنع ذلك تلقائياً:
في المستودع **Settings ← Secrets and variables ← Actions ← New repository secret** أضف:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

## الدخول إلى لوحة الإدارة
- اسم المستخدم: `admin` (يتحول تلقائياً إلى `admin@hbrc-admin.local`)
- كلمة المرور: التي وضعتها في الخطوة 1
- يمكن تغيير كلمة المرور من تبويب **الحساب** داخل اللوحة.

### ما يتحكم فيه المشرف
- **البرامج**: الاسم، الشخص المسؤول، الحالة (حالي/قادم/منتهٍ)، التواريخ، شعار البرنامج، صورة اختيارية، الترتيب، الإخفاء/الإظهار.
- **الفيديو**: وضع العرض (البرامج فقط / الفيديو فقط / البرامج ثم الفيديو)، روابط يوتيوب، رفع ملفات MP4، الترتيب، الصوت.
- **النصوص والشعار**: شعار المؤسسة، شعار المركز، عناوين الشرائح.
- **الشاشة والألوان**: مدة كل شريحة، عدد البرامج في الشريحة، الساعة، العدّ التنازلي، الصور، الألوان، الخط وحجمه.
- **النسخ الاحتياطي**: تنزيل ملف كامل واستعادته.
- **تحديد الحالة تلقائياً**: عند تفعيله ينتقل البرنامج من «قادم» إلى «حالي» إلى «منتهٍ» حسب تواريخه دون تدخل.

## الأمان
- الزوار يستطيعون **القراءة فقط** (والبرامج المخفية لا تظهر لهم).
- الكتابة والحذف ورفع الصور مسموحة **فقط** للبريد المسجّل في جدول `app_admins` — حتى لو أُنشئ حساب آخر بالخطأ.
- المفتاح الموجود في `config.js` مفتاح عام مصمم ليكون ظاهراً؛ الحماية الفعلية في قواعد قاعدة البيانات.
- **لا تضع أبداً** مفتاح `service_role` في أي ملف من ملفات الموقع.

## إضافة نطاق خاص (اختياري)
يمكن ربط نطاق مثل `programs.hbrc.ae` من **Settings ← Pages ← Custom domain** في GitHub بعد إضافة سجل CNAME لدى مزود النطاق.

```
assets/logo.svg       شعار المؤسسة

assets/admin.js       منطق لوحة الإدارة
supabase/schema.sql   إنشاء قاعدة البيانات وصلاحياتها

```

## الفيديو: رفع ملف أم رابط يوتيوب؟
| | رفع ملف MP4 | رابط يوتيوب |
|---|---|---|
| الحد الأقصى | 50 ميغابايت للملف، 1 غيغابايت إجمالاً | بلا حدود |
| استهلاك الخطة المجانية | يُحمَّل مرة واحدة ثم يُحفظ على جهاز التلفاز | لا يستهلك شيئاً |
| الجودة والتشغيل | بلا إعلانات أو شعار يوتيوب | قد يظهر شعار يوتيوب |
| يحتاج إنترنت أثناء العرض | لا (بعد أول تحميل) | نعم |

**التوصية:** المقاطع القصيرة (أقل من دقيقتين) ارفعها كملف MP4 (H.264، دقة 1080p). الفيديوهات الطويلة ضعها على يوتيوب كـ«غير مُدرج» وأضف رابطها.
